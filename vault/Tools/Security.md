# Security

21 curated tools. Pillar: [[Tool Arsenal]] · Up: [[Home]]

## Identity & Access Management

- [Authelia](https://www.authelia.com/) — open-source authentication and authorization server providing 2FA for your apps
- [authentik](https://goauthentik.io/) — flexible, versatile identity provider supporting OAuth 2.0, SAML, LDAP, and RADIUS
- [Keycloak](https://www.keycloak.org/) — open-source identity and access management with SSO, OAuth 2.0, and SAML

## Network Security & Firewall

- [OPNsense](https://opnsense.org/) — FreeBSD-based open-source firewall and router with a modern web interface
- [pfSense CE](https://www.pfsense.org/) — trusted open-source FreeBSD-based firewall and router platform
- [Wazuh](https://www.wazuh.com/) — open-source unified XDR and SIEM platform for threat detection and response

## Network Troubleshooting

- [mitmproxy](https://mitmproxy.org/) — interactive HTTPS proxy for intercepting, inspecting, and modifying network traffic
- [mtr](https://www.bitwizard.nl/mtr/) — combines traceroute and ping into a single powerful network diagnostic tool
- [Wireshark](https://www.wireshark.org/) — world's foremost network protocol analyzer for deep packet inspection

## Penetration Testing Tools

- [Bettercap](https://www.bettercap.org/) — modular, portable MITM framework for network recon and attack
- [DNSDumpster](https://dnsdumpster.com/) — free online DNS reconnaissance service for domain research
- [Ghidra](https://www.ghidra-sre.org/) — NSA-developed software reverse engineering suite
- [Gophish](https://getgophish.com/) — open-source phishing campaign framework for security awareness testing
- [Hydra](https://github.com/vanhauser-thc/thc-hydra) — fast, flexible online password attack tool supporting many protocols
- [Masscan](https://github.com/robertdavidgraham/masscan) — internet-scale port scanner capable of scanning the entire internet in under 6 minutes
- [nmap](https://nmap.org/) — the industry-standard network exploration and security auditing tool
- [OWASP Amass](https://github.com/OWASP/Amass) — in-depth attack surface mapping and asset discovery via multiple OSINT sources
- [OWASP ZAP](https://www.zaproxy.org/) — open-source web application security scanner for finding vulnerabilities
- [RustScan](https://github.com/RustScan/RustScan) — blazing-fast port scanner that pipes results directly into Nmap
- [SpiderFoot](http://www.spiderfoot.net/) — automated OSINT platform with 200+ modules and a web UI
- [theHarvester](https://github.com/laramies/theHarvester) — gather emails, subdomains, hosts, and open ports from public sources
