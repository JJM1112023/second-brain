# Infrastructure

13 curated tools. Pillar: [[Tool Arsenal]] · Up: [[Home]]

## Containers & Virtualization

- [Docker](https://www.docker.com/) — platform for building, shipping, and running applications in containers
- [Podman](https://podman.io/) — daemonless container engine, drop-in alternative to Docker
- [Portainer](https://www.portainer.io/) — lightweight management UI for Docker, Swarm, and Kubernetes environments
- [Proxmox VE](https://www.proxmox.com/) — open-source server virtualization management platform for VMs and containers

## Configuration Management

- [Ansible](https://www.ansible.com/) — agentless IT automation tool for provisioning, configuration management, and deployment
- [Salt](https://saltproject.io/) — event-driven IT automation, remote execution, and configuration management

## Backup & Recovery

- [BorgBackup](https://www.borgbackup.org/) — deduplicating archiver with compression, encryption, and authenticated data integrity
- [rclone](https://rclone.org/) — command-line program for syncing files to and from cloud storage providers
- [restic](https://restic.net/) — fast, secure, verifiable backup program supporting multiple backends

## VPN

- [Headscale](https://github.com/juanfont/headscale) — self-hosted, open-source implementation of the Tailscale control server
- [OpenVPN](https://openvpn.net/) — full-featured SSL/TLS VPN solution with flexible client authentication
- [sshuttle](https://github.com/sshuttle/sshuttle) — poor man's VPN — routes traffic over an SSH connection without root on the server
- [WireGuard](https://www.wireguard.com/) — extremely simple, fast, and modern VPN using state-of-the-art cryptography
