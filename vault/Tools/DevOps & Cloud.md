# DevOps & Cloud

22 curated tools. Pillar: [[Tool Arsenal]] · Up: [[Home]]

## Kubernetes

- [Helm](https://helm.sh/) — package manager for Kubernetes using versioned, templated charts
- [k3s](https://k3s.io/) — lightweight Kubernetes distribution designed for edge, IoT, and resource-constrained environments
- [k9s](https://k9scli.io/) — terminal UI for managing and navigating Kubernetes clusters in real time
- [kubectl](https://kubernetes.io/docs/reference/kubectl/) — official Kubernetes command-line tool for deploying and managing cluster resources
- [kubectx](https://github.com/ahmetb/kubectx) — fast tool for switching between Kubernetes clusters and namespaces
- [Minikube](https://minikube.sigs.k8s.io/) — run a local Kubernetes cluster for development and testing
- [Stern](https://github.com/stern/stern) — multi-pod log tailing for Kubernetes with regex pod/container filtering

## Infrastructure as Code

- [Atlantis](https://github.com/runatlantis/atlantis) — Terraform pull request automation via GitOps with GitHub, GitLab, and Bitbucket
- [OpenTofu](https://opentofu.org/) — open-source, community-driven fork of Terraform under the Linux Foundation
- [Pulumi](https://www.pulumi.com/) — infrastructure as Code using real programming languages: Python, Go, TypeScript, and more
- [Terraform](https://www.terraform.io/) — infrastructure automation using declarative HCL configuration files
- [Terragrunt](https://github.com/gruntwork-io/terragrunt) — thin Terraform wrapper that adds DRY configs, locking, and dependency management

## CI/CD

- [ArgoCD](https://argo-cd.readthedocs.io/) — declarative GitOps continuous delivery for Kubernetes applications
- [Flux](https://fluxcd.io/) — GitOps continuous delivery for Kubernetes with automated reconciliation
- [Jenkins](https://jenkins-ci.org/) — extensible open-source automation server with a vast plugin ecosystem
- [Woodpecker CI](https://woodpecker-ci.org/) — community-driven Drone fork using Docker containers for pipeline steps

## Cloud CLIs

- [AWS CLI](https://aws.amazon.com/cli/) — official command-line interface for managing Amazon Web Services resources
- [Azure CLI](https://learn.microsoft.com/cli/azure) — official command-line interface for managing Microsoft Azure resources
- [Google Cloud CLI](https://cloud.google.com/cli) — official CLI for managing Google Cloud Platform services and resources

## Service Mesh

- [Cilium](https://cilium.io/) — eBPF-based networking, security, and observability for Kubernetes clusters
- [Istio](https://istio.io/) — service mesh providing traffic management, security, and observability for microservices
- [Linkerd](https://linkerd.io/) — lightweight, security-first service mesh for Kubernetes with minimal overhead
