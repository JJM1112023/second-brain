# Other

13 curated tools. Pillar: [[Tool Arsenal]] · Up: [[Home]]

- [Awwwards](https://www.awwwards.com) — curated gallery of award-winning websites; use as a design reference for layout, motion, and visual innovation
- [Dribbble](https://dribbble.com) — design inspiration community for UI mockups, hero layouts, color palettes, and component patterns
- [FGFunnels](https://www.fgfunnels.com/) — all-in-one funnel, course, and membership platform built for coaches and content creators
- [GoHighLevel](https://www.gohighlevel.com/) — white-label CRM and marketing automation platform: funnels, pipelines, SMS/email, calendars, and reputation management in one dashboard

- [Hostinger](https://www.hostinger.com) — affordable web hosting and domain registration; recommended deployment target for Claude-generated static sites
- [MongoDB Atlas](https://www.mongodb.com/atlas) — free-tier cloud database; powers the content store for Claude-built CMS systems with a 512MB free cluster
