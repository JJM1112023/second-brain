# CLI Tools

29 curated tools. Pillar: [[Tool Arsenal]] · Up: [[Home]]

## Shells

- [bash-it](https://github.com/Bash-it/bash-it) — a community Bash framework
- [fish](https://fishshell.com/) — smart and user-friendly command line shell with autosuggestions and syntax highlighting
- [nushell](https://github.com/nushell/nushell) — modern shell written in Rust that treats data as structured tables
- [Oh My ZSH!](https://ohmyz.sh/) — the best framework for managing your Zsh configuration
- [starship](https://starship.rs/) — minimal, blazing-fast, infinitely customizable cross-shell prompt written in Rust
- [thefuck](https://github.com/nvbn/thefuck) — magnificent app that corrects your previous console command
- [tldr](https://github.com/tldr-pages/tldr) — simplified, community-driven man pages with practical examples

## Managers

- [lazydocker](https://github.com/jesseduffield/lazydocker) — simple terminal UI for Docker and docker-compose
- [lazygit](https://github.com/jesseduffield/lazygit) — simple terminal UI for git commands
- [Midnight Commander](https://midnight-commander.org/) — visual file manager, licensed under GNU General Public License
- [nnn](https://github.com/jarun/nnn) — fast, featureful terminal file manager and disk usage analyzer
- [ranger](https://github.com/ranger/ranger) — console file manager with VI key bindings and a preview pane
- [screen](https://www.gnu.org/software/screen/) — full-screen window manager that multiplexes a physical terminal
- [tmux](https://github.com/tmux/tmux/wiki) — terminal multiplexer, lets you switch easily between several programs in one terminal
- [yazi](https://github.com/sxyazi/yazi) — blazing fast terminal file manager built on async I/O

## Text & Search

- [bat](https://github.com/sharkdp/bat) — a cat clone with syntax highlighting and Git integration
- [eza](https://github.com/eza-community/eza) — modern, maintained replacement for ls with colour and icons
- [fd](https://github.com/sharkdp/fd) — simple, fast, and user-friendly alternative to find
- [fzf](https://github.com/junegunn/fzf) — general-purpose command-line fuzzy finder for files, history, and more
- [jq](https://stedolan.github.io/jq/) — lightweight and flexible command-line JSON processor
- [ripgrep](https://github.com/BurntSushi/ripgrep) — recursively searches directories for a regex pattern, faster than grep
- [yq](https://github.com/kislyuk/yq) — command-line YAML, JSON, XML, CSV, and TOML processor
- [zoxide](https://github.com/ajeetdsouza/zoxide) — smarter cd command that learns your most-used directories

## Network

- [Curl](https://curl.haxx.se/) — command line tool and library for transferring data with URLs
- [gnutls-cli](https://gnutls.org/manual/html_node/gnutls_002dcli-Invocation.html) — client program to set up a TLS connection to some other computer
- [HTTPie](https://github.com/jkbrzt/httpie) — user-friendly HTTP client with JSON support, syntax highlighting, and intuitive syntax
- [netcat](http://netcat.sourceforge.net/) — networking utility which reads and writes data across network connections, using the TCP/IP protocol
- [tcpdump](https://www.tcpdump.org/) — powerful command-line packet analyzer

## Databases

- [pgcli](https://github.com/dbcli/pgcli) — postgres CLI with autocompletion and syntax highlighting
